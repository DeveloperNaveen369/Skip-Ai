Skip AI

Privacy Policy

Effective Date: October 2, 2026

App Name: Skip AI
Developer: Naveen Solanki
Package: community.india.hack.in.skipai

Skip AI is an open-source Android AI assistant designed to provide AI functionality directly from selected text. The application follows a local-first approach and does not operate a developer-controlled server for collecting users' conversations or selected text.

1. Information We Collect

Skip AI does not operate a backend service that collects or maintains users' personal information, conversations, selected text, or generated responses.

Depending on the features you use, information may be stored locally on your Android device, including:

  • Chat conversations and chat history.
  • Chat titles and timestamps.
  • Application settings and preferences.
  • AI provider configuration.
  • Your OpenRouter API key, if you choose to use OpenRouter.
  • Downloaded offline AI model files.

This locally stored information is not automatically uploaded to the developer's servers.

2. OpenRouter and Online AI Requests

Skip AI allows users to optionally use online AI services through providers such as OpenRouter.

If you choose to use OpenRouter:

  • You provide your own OpenRouter API key.
  • The API key is stored locally on your device.
  • Prompts, selected text, conversation context, or other content required to generate an AI response may be transmitted to OpenRouter.
  • OpenRouter and the applicable AI model provider may process that information according to their own policies and terms.

Skip AI does not control how third-party providers process information after it has been transmitted to them.

OpenRouter: https://openrouter.ai/

3. OpenRouter API Keys

Users who choose to use OpenRouter may provide their own API key. The key is stored locally on the user's device and is not intentionally transmitted to the Skip AI developer.

Users are responsible for keeping their API keys confidential and should never publicly share them.

4. Offline AI

Skip AI supports offline AI processing using a locally downloaded AI model.

After a compatible model has been downloaded, AI generation can be performed locally on the user's device without requiring an online AI provider.

  • Prompts can remain on the device during offline generation.
  • No OpenRouter API key is required for offline generation.
  • The downloaded model is stored locally.
  • Performance depends on the user's device hardware.

5. Accessibility Service

Skip AI uses Android's AccessibilityService functionality to provide its selected-text assistant feature.

Why AccessibilityService is used

The AccessibilityService is used to detect when the user selects text in another application and display the Skip AI floating assistant for that selected text.

The service may be used to:

  • Detect text-selection events.
  • Obtain text selected by the user when supported by the application.
  • Display the Skip AI floating interface.
  • Allow actions such as asking AI about selected text, summarizing, simplifying, and translating.
  • Assist with writing a generated response into a supported text input when the user explicitly chooses that feature.

What AccessibilityService is not used for

Skip AI does not use AccessibilityService for advertising tracking, surveillance, or collecting a user's general activity across applications.

The service is specifically used to provide the selected-text assistant functionality.

Users can disable the AccessibilityService at any time through Android Accessibility settings. Disabling it will prevent the selected-text assistant functionality from working.

6. Overlay Permission

Skip AI may request Android's overlay permission so that it can display its floating assistant over other applications after the user grants permission.

The overlay is used to display the Skip AI interface and AI responses.

7. Chat History

Skip AI can store conversations locally using the Android device's local database.

Local chat storage allows the application to restore conversations after the application is closed and continue conversations across application sessions.

The developer does not receive these locally stored conversations through a Skip AI backend.

When an online AI provider is used, relevant conversation content may be transmitted to that provider to generate a response.

8. AI-Generated Content

Skip AI provides AI-generated responses. AI responses may be inaccurate, incomplete, outdated, or unsuitable for a particular situation.

Important information should be independently verified. Skip AI should not be considered a replacement for qualified professional advice, including medical, legal, or financial advice.

9. Data Sharing

Skip AI does not sell, rent, or provide users' personal information to advertisers.

Information may leave the device when the user intentionally uses a third-party online AI provider. In that situation, relevant information is transmitted to the selected provider to process the request.

10. Advertising and Tracking

Skip AI does not intentionally use users' personal information for behavioral advertising or cross-application advertising tracking.

11. Permissions

  • Accessibility Service: Used for selected-text detection and the floating AI assistant.
  • Overlay Permission: Used to display the floating Skip AI interface over other apps.
  • Internet: Used for online AI requests and downloading required resources, including offline AI models.

12. Security

Skip AI takes reasonable measures to protect locally stored application information.

Where supported, sensitive credentials such as API keys are stored using Android security mechanisms.

However, no software or storage system can be guaranteed to be completely secure. Users are responsible for protecting their Android device and API credentials.

13. Children's Privacy

Skip AI is not specifically designed to collect personal information from children. We do not knowingly operate a service designed to collect children's personal information.

14. Data Deletion

Since Skip AI does not maintain a developer-controlled database containing users' conversations, users can manage locally stored information through Android and the application.

Users may:

  • Delete conversations where the application provides that option.
  • Delete application data through Android settings.
  • Remove their locally stored API configuration.
  • Disable the AccessibilityService.
  • Uninstall Skip AI.

Information already transmitted to a third-party AI provider is subject to that provider's own privacy policies and deletion procedures.

15. Open Source and Transparency

Skip AI is a fully open-source project. The source code is publicly available so users and developers can inspect how the application works, including its data handling and AI functionality.

GitHub Repository: https://github.com/DeveloperNaveen369/Skip-Ai
